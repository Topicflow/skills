# Out of scope

Designs we considered and decided against, one file each. Every file says what was proposed,
why it was rejected, what we do instead, and when to revisit.

This folder exists so a decision made once stays made. Before proposing a structure change,
check here — if the idea has a file, the burden is on the new argument, not on re-litigating
the old one. (Pattern borrowed from mattpocock/skills `.out-of-scope/`.)

**Rejected** ideas live here. **Deferred** ideas — good, just not now — live in the internal post-v1
backlog.
