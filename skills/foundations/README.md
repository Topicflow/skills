# Foundations

The three skills the others lean on — none of them is a task in itself.

- **[management-rules](./management-rules/SKILL.md)** — the seventeen rules (P1-P17) behind the
  library, written as pass/fail checks. Every other skill runs these against its own drafts
  before showing them. Also the right answer when someone asks what good practice says about a
  situation.
- **[save-private-note](./save-private-note/SKILL.md)** — the memory habit. People say the most
  useful things in passing ("she hates public praise", "he's never run a migration"); this
  catches them and restates them in one third-person sentence. Every other skill hands its
  durable findings here (library convention 3). **There is no private-note tool yet**
  ([TF-1595](https://linear.app/topicflow/issue/TF-1595)), so today it hands the sentence back —
  and it never uses 1-on-1 notes as a substitute, because those are shared with the other person.
- **[ask-topicflow](./ask-topicflow/SKILL.md)** — user-invoked (`/ask-topicflow`). The map of the
  library: which skill fits the moment, what good practice says (with the rule it rests on), and
  what these skills can and cannot see in Topicflow today.

`management-rules` and `save-private-note` fire while other work is happening; nobody sets out to
run them. `ask-topicflow` is the one you type when you are not sure what to type.
