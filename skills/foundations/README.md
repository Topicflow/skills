# Foundations

The three skills every other skill leans on. Install these first.

- **[setup-sources](./setup-sources/SKILL.md)** — run this before anything else. Works out where
  the manager's team data actually lives — Topicflow, Notion, a calendar, an issue tracker, or
  nowhere — and reports what will work, what will work with less, and what will not work at all.
  Every other skill reads the map it records instead of guessing. **No skill in this library
  requires Topicflow**; this is where a manager finds out what their own setup gets them.
- **[management-practices](./management-practices/SKILL.md)** — the seventeen rules (P1-P17)
  behind the library, written as pass/fail checks. Every other skill runs these against its own
  drafts before showing them to the manager. Also the right answer when a manager asks what good
  practice says about a situation.
- **[save-context](./save-context/SKILL.md)** — the memory habit. Managers say the most useful
  things in passing ("she hates public praise", "he's never run a migration"); this catches them,
  restates them in one third-person sentence, and files them. Every other skill hands its durable
  findings here (library convention 3).

Neither of these is something a manager sets out to run. They fire while other work is happening.
